판별 방법

  1. 앱에서 선택한 좌표와 위 좌표가 같으면 적용된 것입니다.
  2. 실제 위치가 보이면 확장이 꺼져 있거나 이 사이트에서 허용되지 않은 상태입니다. Safari 주소창 왼쪽의 ⋯(또는 aA) 메뉴에서 확장 상태를 확인하세요.
  3. "configuration unavailable" 오류는 확장이 앱과 연결되지 못한 상태입니다. 앱을 한 번 열고 새로고침하세요. 이때 실제 위치는 전달되지 않습니다(안전 실패).

IP 기반 위치는 이 도구로 바뀌지 않습니다. 브라우저 위치 API 값만 바뀝니다.
