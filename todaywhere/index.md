# 오늘어디 (TodayWhere)

오늘어디는 사용자의 현재 위치와 관심 조건을 바탕으로 주변 음식점, 카페, 주차장, 지역 혼잡도 정보를 안내하는 iOS 앱입니다.

현재 개발 중인 서비스이며, 정식 출시 전 API 연동 및 기능 검증 단계입니다.

## 주요 기능

- 주변 음식점 및 카페 탐색
- 사용자 조건 기반 장소 추천
- 주변 주차장 정보 안내
- 서울 지역 실시간 주차 정보 안내
- 서울 주요 지역 혼잡도 정보 안내
- 외부 지도 앱 및 웹페이지 연결을 통한 길찾기와 장소 상세 확인

## 공공데이터 활용

오늘어디는 서울 열린데이터광장의 데이터를 활용하여 서울 지역 공영주차장 정보와 주요 지역 혼잡도 정보를 앱 내에서 안내할 예정입니다.

활용 예정 데이터는 다음과 같습니다.

- 서울시 주차장 실시간 주차정보
- 서울시 실시간 도시데이터

해당 데이터는 사용자가 식당, 카페, 주변 장소를 방문하기 전에 주차 가능성 및 지역 혼잡도를 참고할 수 있도록 제공됩니다.

## 개인정보

오늘어디는 위치 기반 추천 기능을 제공하기 위해 사용자의 위치 권한을 요청할 수 있습니다. 위치 정보는 주변 장소 검색과 추천 목적으로만 사용되며, 별도 동의 없이 외부에 판매하거나 공유하지 않습니다.

자세한 개인정보 처리방침은 정식 출시 전 별도 페이지로 제공될 예정입니다.
