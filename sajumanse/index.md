개인정보처리방침 (Korean)
사주만세 개인정보처리방침

본 방침은 사주만세 앱(이하 "앱")의 개인정보 수집 및 이용에 관한 사항을 안내합니다.

1. 수집하는 정보
앱은 사용자의 개인정보를 직접 수집하거나 외부 서버에 저장하지 않습니다. 앱에서 입력한 모든 데이터(생년월일, 생시, 이름, 저장된 사주 목록, AI 상담 기록)는 사용자의 기기 내에만 저장됩니다.

2. 데이터 저장 방식
- 사주 입력값·저장 목록·AI 상담 기록·AI 해석 결과: 기기 내 UserDefaults에 저장
- AI API 키: 기기 내 Keychain에 암호화 저장 (외부 전송 없음)

3. 기기 내 AI (Apple Intelligence)
Apple Intelligence를 지원하는 기기에서는 API 키 없이 기기 내 AI로 풀이를 받을 수 있습니다. 이 방식은 처리 전 과정이 기기 안에서 이루어지며, 사주 데이터가 기기 밖으로 전송되지 않습니다.

4. 클라우드 AI 해석 기능 (선택적 사용)
앱은 선택적으로 클라우드 AI 해석 기능을 제공합니다. 이 기능은 사용자가 직접 발급한 API 키(Anthropic Claude, Google Gemini, OpenAI, xAI Grok 중 선택)를 등록해야만 활성화됩니다(BYOK — Bring Your Own Key 방식).

클라우드 AI 해석 기능 사용 시:
- 사주 데이터(생년월일, 생시, 성별, 이름, 사주 분석 결과)가 사용자가 선택한 AI 제공사의 API 서버로 전송됩니다.
- 손금 보기 기능 사용 시 사용자가 직접 선택하거나 촬영한 손 사진이 AI 제공사의 API 서버로 전송됩니다. 사진은 풀이 요청에만 사용되며 앱에 별도로 보관되지 않습니다.
- 꿈해몽·육효·궁합 등 다른 항목도 해당 기능을 사용할 때에만 관련 내용이 전송됩니다.
- 데이터는 앱 개발사가 아닌 사용자가 선택한 AI 제공사(Anthropic, Google, OpenAI, xAI)의 개인정보처리방침에 따라 처리됩니다.
- 항목마다 사용할 AI를 따로 지정할 수 있으며, 클라우드 AI를 사용하지 않으면 외부로 전송되는 데이터가 없습니다.

5. 제3자 공유
앱 개발사는 사용자 데이터를 수집하거나 제3자와 공유하지 않습니다. AI 기능 사용 시 데이터는 사용자가 직접 선택한 AI 제공사에만 전달되며, 앱 개발사는 이 데이터에 접근하지 않습니다.

6. 광고 및 분석
앱은 광고 SDK, 분석 SDK, 추적 코드를 일절 포함하지 않습니다. 앱 내 구입이나 구독도 없습니다.

7. 외부 서버
앱 개발사가 운영하는 외부 서버는 없습니다. 클라우드 AI 기능을 사용하지 않는 경우 모든 계산(사주, 오행, 대운·세운·월운, 토정비결, 궁합, 육효 등)은 기기 내에서 완전히 처리됩니다.

8. 데이터 보관 및 삭제
앱의 모든 데이터는 앱이 설치된 기간 동안 사용자의 기기에만 보관됩니다. 별도의 자동 삭제 기한은 없습니다.

데이터 삭제 방법:
- 저장된 사주 개별 삭제: 저장된 사주 목록에서 해당 항목 삭제 (그 사주에 귀속된 AI 상담과 저장된 해석도 함께 삭제됩니다)
- 상담 기록 개별 삭제: 상담 기록 화면에서 해당 상담 삭제
- 상담 기록 전체 삭제: 설정 → AI 해석 → 상담 기록 → 전체 삭제
- 저장된 AI 해석 삭제: 설정 → AI 해석 → 저장된 AI 해석 → 전체 초기화 (항목별 초기화는 항목별 AI 설정에서)
- API 키 삭제: 설정 → AI 해석에서 키 삭제
- 앱 전체 데이터 삭제: iPhone에서 앱을 삭제하면 앱 관련 모든 데이터가 함께 영구 삭제됩니다.

9. 사진 접근 권한
손금 보기 기능에서만 사진 라이브러리 또는 카메라 접근을 요청합니다. 권한은 iPhone 설정 → 개인정보 보호 및 보안에서 언제든지 해제할 수 있습니다.

10. 문의
개인정보 및 앱 이용 관련 문의는 앱 스토어 지원 페이지를 이용해 주세요.

Privacy Policy (English)
Privacy Policy for 사주만세 (SajuManse)

This policy describes how the 사주만세 app handles your information.

1. Data Collection
SajuManse does not collect or store personal information on external servers. All data you enter (date of birth, time of birth, name, saved saju records, AI consultation history) is stored exclusively on your device.

2. Data Storage
- Saju input data, saved records, AI consultation history, and saved AI interpretations: Stored locally in UserDefaults on your device
- AI API keys: Stored securely in the device Keychain, encrypted and never transmitted externally

3. On-Device AI (Apple Intelligence)
On devices that support Apple Intelligence, you can receive interpretations using on-device AI without any API key. With this option, all processing happens on the device and your saju data never leaves it.

4. Cloud AI Interpretation Features (Optional)
The app optionally provides cloud AI interpretation features. These features are only activated when you register your own API key from a supported AI provider (Anthropic Claude, Google Gemini, OpenAI, or xAI Grok) — this is a Bring Your Own Key (BYOK) model.

When using cloud AI interpretation features:
- Your saju data (date of birth, time of birth, gender, name, and saju analysis results) is sent to the API servers of the AI provider you selected.
- When using the palm reading feature, the hand photo you select or capture is sent to the API servers of the AI provider you selected. Photos are used only for the interpretation request and are not otherwise retained by the app.
- Other features such as dream interpretation, hexagram divination, and compatibility send their related content only when you use them.
- Your data is processed according to the privacy policy of the AI provider you chose (Anthropic, Google, OpenAI, or xAI), not this app's developer.
- You may assign a different AI provider per feature. If you do not use cloud AI, no data is transmitted externally.

5. Third-Party Sharing
The app developer does not collect or share your data with any third parties. When using AI features, data is sent only to the AI provider you directly selected. The app developer has no access to this data.

6. Advertising and Analytics
The app contains no advertising SDKs, analytics SDKs, or tracking code of any kind. There are no in-app purchases or subscriptions.

7. External Servers
The app developer operates no external servers. When cloud AI features are not in use, all calculations (saju chart, five elements, fortune cycles, Tojeong, compatibility, hexagram divination, and so on) are performed entirely on-device.

8. Data Retention and Deletion
All app data remains on your device for as long as the app is installed. There is no automatic deletion period.

How to delete your data:
- Delete a saved saju: Remove the entry from the saved saju list (its AI consultations and saved interpretations are removed with it)
- Delete a single consultation: Remove it from the consultation history screen
- Delete all consultations: Settings → AI Interpretation → Consultation History → Delete All
- Delete saved AI interpretations: Settings → AI Interpretation → Saved AI Interpretations → Clear All (per-feature clearing is available in per-feature AI settings)
- Delete API keys: Settings → AI Interpretation
- Delete everything: Deleting the app from your iPhone permanently removes all associated data.

9. Photo Access
Photo library or camera access is requested only for the palm reading feature. You can revoke it at any time in iPhone Settings → Privacy & Security.

10. Contact
For privacy or general app questions, please use the support link on the App Store page.
