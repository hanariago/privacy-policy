개인정보처리방침 (Korean)
사주만세 개인정보처리방침

본 방침은 사주만세 앱(이하 "앱")의 개인정보 수집 및 이용에 관한 사항을 안내합니다.

1. 수집하는 정보
앱은 사용자의 개인정보를 직접 수집하거나 외부 서버에 저장하지 않습니다. 앱에서 입력한 모든 데이터(생년월일, 생시, 저장된 사주 목록)는 사용자의 기기 내에만 저장됩니다.

2. 데이터 저장 방식
- 사주 입력값 및 저장 목록: 기기 내 UserDefaults에 저장
- AI API 키: 기기 내 Keychain에 암호화 저장 (외부 전송 없음)

3. AI 해석 기능 (선택적 사용)
앱은 선택적으로 AI 해석 기능을 제공합니다. 이 기능은 사용자가 직접 발급한 API 키(Anthropic Claude, Google Gemini, OpenAI 중 선택)를 등록해야만 활성화됩니다(BYOK — Bring Your Own Key 방식).

AI 해석 기능 사용 시:
- 사주 데이터(생년월일, 생시, 성별, 사주 분석 결과)가 사용자가 선택한 AI 제공사의 API 서버로 전송됩니다.
- 손금 보기 기능 사용 시 사용자가 직접 선택한 손 사진이 AI 제공사의 API 서버로 전송됩니다.
- 데이터는 앱 개발사가 아닌 사용자가 선택한 AI 제공사(Anthropic, Google, OpenAI)의 개인정보처리방침에 따라 처리됩니다.
- AI 기능을 사용하지 않으면 외부로 전송되는 데이터가 없습니다.

4. 제3자 공유
앱 개발사는 사용자 데이터를 수집하거나 제3자와 공유하지 않습니다. AI 기능 사용 시 데이터는 사용자가 직접 선택한 AI 제공사에만 전달되며, 앱 개발사는 이 데이터에 접근하지 않습니다.

5. 광고 및 분석
앱은 광고 SDK, 분석 SDK, 추적 코드를 일절 포함하지 않습니다.

6. 외부 서버
앱 개발사가 운영하는 외부 서버는 없습니다. AI 기능을 사용하지 않는 경우 모든 계산(사주, 오행, 대운/세운/월운 등)은 기기 내에서 완전히 처리됩니다.

7. 문의
개인정보 관련 문의는 앱 스토어 지원 페이지를 이용해 주세요.

Privacy Policy (English)
Privacy Policy for 사주만세 (SajuManse)

This policy describes how the 사주만세 app handles your information.

1. Data Collection
SajuManse does not collect or store personal information on external servers. All data you enter (date of birth, time of birth, saved saju records) is stored exclusively on your device.

2. Data Storage
- Saju input data and saved records: Stored locally in UserDefaults on your device
- AI API keys: Stored securely in the device Keychain, encrypted and never transmitted externally

3. AI Interpretation Features (Optional)
The app optionally provides AI-powered interpretation features. These features are only activated when you register your own API key from a supported AI provider (Anthropic Claude, Google Gemini, or OpenAI) — this is a Bring Your Own Key (BYOK) model.

When using AI interpretation features:
- Your saju data (date of birth, time of birth, gender, and saju analysis results) is sent to the API servers of the AI provider you selected.
- When using the palm reading feature, the hand photo you select is sent to the API servers of the AI provider you selected.
- Your data is processed according to the privacy policy of the AI provider you chose (Anthropic, Google, or OpenAI), not this app's developer.
- If you do not use AI features, no data is transmitted externally.

4. Third-Party Sharing
The app developer does not collect or share your data with any third parties. When using AI features, data is sent only to the AI provider you directly selected. The app developer has no access to this data.

5. Advertising and Analytics
The app contains no advertising SDKs, analytics SDKs, or tracking code of any kind.

6. External Servers
The app developer operates no external servers. When AI features are not in use, all calculations (saju chart, five elements, fortune cycles, etc.) are performed entirely on-device.

7. Contact
For privacy-related questions, please use the support link on the App Store page.
